# KnowledgeRetention

> **Archived project** — This repository contains an older version of KnowledgeRetention and is no longer actively developed.

KnowledgeRetention is a learning application built with **Unity and C#** designed to help users actively retain knowledge through customizable quizzes and repeated testing.

The project explored different ways of testing knowledge beyond traditional multiple-choice questions, including **free-form answers evaluated locally using an LLM**.

## ✨ Features

* 📚 **Categories and subcategories** to organize knowledge
* 📝 **Custom quiz creation**
* ❓ Multiple question and answer formats
* 🖼️ Support for image-based questions
* 🔀 Randomized multiple-choice answers

* 🤖 **Local AI-assisted answer evaluation**
* 💬 AI-generated feedback and explanations for incomplete or incorrect answers
* 📱 Designed as an Android application

## 🤖 Local AI Evaluation

One of the main experiments in KnowledgeRetention was allowing users to answer questions naturally instead of requiring an exact predefined response.

A local language model can evaluate a user's answer and determine whether it is:

* Correct
* Partially correct
* Incorrect

It can also provide an explanation when the submitted answer is incomplete or incorrect.

The goal was to make self-testing more flexible while keeping AI processing local to the device.

## 💡 Project Goal

KnowledgeRetention started as an experiment around a simple idea:

> **Learning something once is not enough — retaining it requires actively recalling it.**

The application was designed around creating a personal collection of questions and regularly testing yourself on the information you want to remember.

Rather than limiting quizzes to simple multiple-choice questions, the project also explored using local AI to evaluate natural-language answers.
